# 彩虹卡丁车 | Rainbow Kart
一款用 HTML5 Canvas 制作的轻量级卡通赛车小游戏，支持 iPhone/Android 触屏和电脑键盘。

🎮 **游玩网址（GitHub Pages 启用后）：https://zhilangnp-lgtm.github.io/rainbow-kart/**

## 开启网页版（仓库所有者操作）
1. 打开 https://github.com/zhilangnp-lgtm/rainbow-kart/settings/pages
2. Build and deployment → Source 选择 **Deploy from a branch**
3. Branch 选择 **main**，文件夹选择 **/(root)**，点击 **Save**
4. 在页面显示“Your site is live”后，用 Safari 或浏览器打开上面的游玩网址。

## 操作
- 手机：屏幕左右按钮控制方向，使用道具按钮触发道具。
- 电脑：方向键或 A/D 转向，空格使用道具。
- 玩法：3 圈竞速、3 名 AI 对手、金币、道具、排名与计时。

技术思路参考 [javascript-racer](https://github.com/jakesgordon/javascript-racer)；游戏代码和美术独立实现，不使用其非自由授权的音乐或精灵图片。非任天堂官方游戏。
